# ECHO-WSP v0.4.1 — Lossless Acoustic Return

La v0.4.0 podía reconocer el saludo de cinco tonos con `contact`, pero el ciclo:

```text
contact → JSON → audio → listen
```

perdía la acción, el tiempo, el espacio y parte de la emoción. La máscara musical
era perceptiva y `listen` reconstruía el paquete mediante heurísticas.

La v0.4.1 conserva esa máscara musical y añade al final del WAV una ráfaga FSK
con el paquete binario WSP completo:

```text
W41A + longitud + Message.to_bytes() + CRC32
```

Esto permite recuperar exactamente:

- origen, relación, acción y destino;
- tiempo y espacio;
- los seis ejes emocionales cuantizados por el formato binario WSP;
- conceptos derivados transportados en el binario.

Los metadatos diagnósticos de `meta` no forman parte de `Message.to_bytes()` y no
se transmiten. Si no existe un tráiler v0.4.1 válido, el programa utiliza el
listener heurístico anterior para conservar compatibilidad.

```bash
wsp audio --json saludo.json -o saludo_recuperado.wav
wsp listen saludo_recuperado.wav --compact
wsp listen saludo_recuperado.wav > saludo_recuperado.json
wsp glyph --json saludo_recuperado.json -o saludo_recuperado.svg
```
